## About the Project

Zafran is a restaurant management and online ordering system developed as a university Project-Based Learning (PBL) project for the **Data Structures & Object-Oriented Programming (DSOOP)** course.

Inspired by traditional dining, Zafran combines a restaurant-themed web interface with a C++ backend to demonstrate the practical application of programming concepts in a restaurant environment.

From browsing the menu to placing orders and generating receipts, the system brings essential restaurant operations together in one platform.

## Features

- Digital Menu — Browse dishes with photographs and descriptions.
- Online Ordering — Place dine-in and pickup orders.
- Order Management — Process and manage customer orders.
- Receipt Generation — Generate unique order receipts.
- Database Integration — Store and manage order records using SQLite.
- Restaurant Information — Explore restaurant details and visiting information.
- Responsive Interface — Navigate through a web-based experience.
